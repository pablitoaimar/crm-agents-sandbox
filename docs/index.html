CRM agents sandbox: run viewer

Two AI agents plan a CRM email campaign for a fictional car rental company. The agents propose. Code checks every request and can say no. A person approves before anything is sent. Statistics measure the result.

Who decides what

  1. 1Segment · Agent proposes the audience in SQL, Code checks it
  2. 2Exclusions · Code removes people without consent or contacted in the last 7 days
  3. 3Email copy · Agent writes variants, Code brand linter checks them
  4. 4A/B plan · Code random split + 10% holdout that gets nothing
  5. 5Approval · Human reads the plan and says yes or no
  6. 6Send · Code simulated here
  7. 7Evaluation · Code significance test against the holdout
